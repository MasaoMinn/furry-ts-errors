# furry-ts-errors

Showing different furry illusions according to the error type, bringing more fun to the programming.
You can customize **your own illustrations** now!

![furry-ts-errors](https://cdn.jsdelivr.net/gh/MasaoMinn/furry-ts-errors@feature/fursona/apps/vscode-extension/icon.png)

Github Repository: [furry-ts-errors](https://github.com/masaominn/furry-ts-errors "furry-ts-errors")

VSCode Extension forked from [yoavbls/pretty-ts-errors](https://github.com/yoavbls/pretty-ts-errors "yoavbls/pretty-ts-errors")

## Brief Usage Instruction

### Installation

Search `Furry TypeScript Errors` in VSCode Extension marcket, install me.

![](/apps/vscode-extension/assets/marcket.png)

Find me in the activity bar. Click the bow tie icon, the side panel will be opened.

![](/apps/vscode-extension/assets/guide1.png)

I recommend to drag the icon into file explorer, so that you can watch the file explorer with the panel open.

![](/apps/vscode-extension/assets/guide2.png)

Final status

![](/apps/vscode-extension/assets/guide3.png)

If you have more creative ideas or want to support my development on the ideals above, create a issue!
